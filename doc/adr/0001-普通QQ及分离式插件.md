# ADR-0001：普通 QQ 账号 + NapCat + AstrBot Monorepo 插件

- 状态：Accepted
- 日期：2026-10-13

## 决定

- 仅支持普通 QQ 专用账号，使用 NapCat 提供 OneBot v11 反向 WebSocket，AstrBot 处理模型和插件。
- 仓库为 Monorepo，插件位于 `astrbot_plugin_qq_smartbot/`，部署时仅安装该子目录。
- 所有群消息先通过无模型 Router 决策。默认关闭未匹配消息的后续事件流。
- 第一阶段使用本地 JSON 热更新和 SQLite；WebUI/.NET 工具服务列为后续可选模块。

## 权衡

- 普通账号满足个人身份接入需求，但非官方方案有封控风险，账号登录态须隔离。
- 复用 AstrBot 比自研 QQ 协议/LLM 框架成本低，但受宿主生命周期及插件加载机制约束。
- 静默事件捕获引入隐私义务，仅限获群主许可的群与规则，默认最小化保存字段。
