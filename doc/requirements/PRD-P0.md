# QQ SmartBot P0 / P1 最小验收需求

状态：评审通过，可开发；真实 QQ 验收待执行。版本：2026-10-13。

## 必须实现

1. 仅对环境变量 `SMARTBOT_GROUP_IDS` 明确授权的 QQ 群进行处理，且仅接收 `aiocqhttp`（NapCat/OneBot v11）事件。
2. `@机器人`：使用平台类型化 At 消息段判断，交由 AstrBot 默认人格/LLM 处理。文本中仅有字面 `@机器人` 不视为合法唤醒。
3. 无 @ 的 `!roll`、`!choose`、`!help`：本地执行，模型调用计数为 0。
4. 普通消息：未匹配任何规则，静默并阻断后续默认 LLM。
5. 精确关键词回复：仅互动模式，受规则冷却时间限制。
6. 含关键词组的活动意向：观察/互动模式并显式启用捕获后，静默写入 `candidate` 记录；**不代表正式活动**。
7. 规则 JSON 可运行时变更；非法配置维持上一版有效规则，删除配置关闭自动规则。
8. 消息幂等：稳定平台消息 ID 按群去重；事件候选只记录群、发起者、规则、事件类型、游戏、时间，不保存聊天原文。
9. 生产账号登录态、Token 和配置文件不得纳入公开仓库。

## 本期不做

正式活动确认/报名、MCP Agent、语义识别、私聊 Agent、通用正则、可视化管理后台、自动群发。后续阶段按路线图推进。

## 通过门槛

- 单元测试通过；非法/越权/普通消息不触发 LLM 的本地决策成立。
- 真实 NapCat -> AstrBot 链路接通；人工核验 0 Token、恰好一条回复、不串群、重复消息不重复执行。
- 未完成现场验证不得声称 P0 已上线验收。
