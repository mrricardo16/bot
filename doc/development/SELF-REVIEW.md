# QQ SmartBot 自评审记录

日期：2026-10-13；范围：普通 QQ / NapCat / AstrBot，规则驱动群聊消息处理，P0/P1。

## 结论

**条件通过（可开始离线开发，未批准真实上线）**。QQ 接入、框架分流与 Provider 零调用必须通过现场端到端测试。

## 风险与决策

| 编号 | 风险 | 严重度 | 处理 |
|---|---|---|---|
| R-01 | AstrBot 内置唤醒或其他插件导致无 @ 产生 Token | 高 | 高优先级事件监听器，对非明确 @ 消息 stop_event；现场统计 LLM 请求数 |
| R-02 | Monorepo 不满足插件根目录识别 | 高 | 只部署子目录到 `data/plugins`，添加 README |
| R-03 | 公开 Git 仓库泄漏账号/令牌/群记录 | 高 | 仅提交配置模板；数据目录、日志、密钥统一忽略 |
| R-04 | 正则 ReDoS / 任意工具执行 | 高 | P0 只支持 exact/contains_all，禁止命令/代码注入型动作 |
| R-05 | 活动意向误判成正式活动 | 中 | 仅保存 candidate；不可自动报名或主动提醒 |
| R-06 | SQLite 幂等但崩溃时消息丢失 | 中 | 明确 at-most-once，后续用 outbox/补偿改善 |
| R-07 | 无上限存储历史消息与事件 | 中 | P0 原文不落库，启动清理过期候选/历史去重键 |
| R-08 | 修改运行时 JSON 导致解析失败 | 中 | 类型校验 + 上一版有效配置回退；删除文件关闭规则 |
| R-09 | NapCat 普通账号风控及兼容风险 | 中 | 独立小号、最小权限、部署日志、恢复手册 |
| R-10 | 群内被动分析的隐私合规问题 | 高 | 群主授权、群成员事先知情、显式 capture_enabled |

## 审查边界

离线单元测试能证明路由及数据库状态的确定性行为，不等同于验证 QQ 消息结构、插件生命周期和框架事件传播。真实运行门槛见 `doc/testing/P0-checklist.md`。
